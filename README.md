🌈 Spectrum

A full-stack application built with modern web technologies, focused on creating a clean, scalable, and user-friendly experience.

🚧 Status: 50% Complete Actively in Development

Spectrum is a project I'm building to learn, experiment, and implement real-world full-stack concepts.

There are still many features planned, and the project is continuously evolving.

---

🚀 Current Features

🔐 Authentication

- User registration & login
- JWT authentication
- Password hashing with bcrypt
- Google OAuth
- Protected routes
- Cookie-based authentication

👤 User System

- User account management
- Authentication state handling
- Secure user sessions

🖼️ Media Handling

- Image uploads
- ImageKit integration
- Multer for handling uploaded files

🎨 Frontend

- React
- Vite
- Tailwind CSS
- React Router
- Responsive UI
- Redux Toolkit for state management

⚙️ Backend

- Node.js
- Express.js
- REST APIs
- MongoDB
- Mongoose
- Request validation
- Error handling
- API logging
